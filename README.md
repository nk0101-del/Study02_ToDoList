# Study02_ToDoList

매일 10~20개 정도의 할 일을 관리하는 개인용 웹 앱입니다. 순수 자바스크립트로 만들었고, 서버나 설치 없이 브라우저에서 바로 실행됩니다.

## 주요 기능

- 할 일 추가, 수정, 삭제
- 완료 체크
- 카테고리 분류(업무, 개인, 공부)와 카테고리별 필터
- 진행률 보기(전체와 카테고리별)
- 새로고침해도 데이터 유지(브라우저 `localStorage`에 저장)

## 배포 주소

https://nk0101-del.github.io/Study02_ToDoList/

## 실행 방법

위 배포 주소로 접속하거나, 내려받은 `index.html` 파일을 브라우저로 열면 됩니다. 별도의 빌드나 설치는 필요 없습니다.

## 사용법

- 입력창에 내용을 쓰고 카테고리를 고른 뒤 Enter 또는 **추가** 버튼을 누릅니다.
- 체크박스로 완료 여부를 바꿉니다.
- **수정**을 누르면 내용과 카테고리를 바꿀 수 있습니다. Enter로 저장하고 Esc로 취소합니다.
- **삭제**를 누르면 **정말 삭제**와 **취소** 버튼이 나타나고, **정말 삭제**를 눌러야 지워집니다.
- 상단 진행률은 필터와 관계없이 전체 할 일을 기준으로 계산합니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 스타일 |
| `app.js` | 동작과 저장 로직 |
| `PRD.md` | 제품 요구사항 문서 |

## 참고

데이터는 사용 중인 브라우저에만 저장됩니다. 브라우저의 사이트 데이터를 지우거나 다른 브라우저에서 열면 목록이 보이지 않습니다.
